# Hi, I'm Doğu 👋

I build small products with generative AI and figure out how to get people to try them.

- 🚀 **[launchkit](https://github.com/dogubalabann-alt/launchkit)**: one-line pitch in, launch kit out. It writes the X thread and LinkedIn post, then renders a hero image and a teaser video, all with models on [fal](https://fal.ai).
- 📰 **Mitos** (private, in progress): a good-news app for Turkish readers. A Python worker scrapes the news, Claude scores the sentiment, and an Expo/React Native app serves only the positive stories. Supabase backend, CI and scheduled jobs on GitHub Actions. Its legal pages are public: [mitos-legal](https://github.com/dogubalabann-alt/mitos-legal).

**Tools I use:** TypeScript · Python · React Native (Expo) · Supabase/Postgres · GitHub Actions · LLM and generative media APIs (fal, Claude)
